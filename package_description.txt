Le package express permet de faire des API Rest

Le package serve-favicon permet d'ajouter un favicon (Logo d'une page) sur le navigateur

Le package morgan permet de loggeur les donnees dans le terminale

Le package nodemon permet de relancer automatiquement l'app a chaque modification dans le code de l'app en cours d'execution

Le package body-parser permet de transformer les json en string et inversement. cela est necessaire pour l'echange des donnees provenant de http (string) et ceux du serveur (json)

Le package bcrypt permet le cryptage des mots de passes 

Le package jsonwebtoken permet la generation des token apres l'authentification des utilisateurs, se jeton lui permet d'acceder aux ressources protege pour une duree donnee
